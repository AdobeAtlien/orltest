# accordion-image

Custom **accordion** block. Purpose: accordion beside a photo that swaps to the open item image.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: label cell | content cell (text, links, optional image); image may also be its own cell.
