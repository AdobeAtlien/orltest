# widget-ugc-gallery

Custom **widget** block. Purpose: lazy-loaded third-party user-generated social photo gallery.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell with a link to a widget page under /widgets/, a gallery script URL (.js; ?id= becomes the script id, other params data attributes), or an embeddable gallery URL (iframe).

No variations.
